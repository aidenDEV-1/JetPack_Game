# 보안 및 운영 경계

## 현재 프로토타입

- 회사 Entra ID Single-tenant 사용자만 로그인하도록 설계한다.
- 클라이언트가 보낸 거리·코인·점수를 서버에서 그대로 저장한다.
- 따라서 개발자 도구로 요청을 바꾸면 랭킹과 코인을 조작할 수 있다.
- 이 방식은 사내 게임성 검증까지만 허용한다.

## 정식 보상 전환 전 필수 작업

1. 플레이 세션을 서버에서 발급한다.
2. 거리·속도·아이템 획득 이벤트를 서버 검증용으로 기록한다.
3. 코인 지급과 최고 기록 갱신을 서버 authoritative 방식으로 계산한다.
4. 중복 요청 idempotency key와 rate limit을 추가한다.
5. 관리자 감사 로그와 이상 기록 차단 정책을 추가한다.

## 비밀값과 개인정보

- Client Secret, Cosmos credential, Static Web Apps token은 GitHub secret/Key Vault에만 둔다.
- 공개 랭킹에는 Entra 표시 이름·게임 거리·코인만 표시한다.
- 이메일·사번·tenant ID는 랭킹 문서에 저장하거나 표시하지 않는다.
- 제공받은 원본 얼굴 사진은 저장소와 배포물에 포함하지 않는다.
