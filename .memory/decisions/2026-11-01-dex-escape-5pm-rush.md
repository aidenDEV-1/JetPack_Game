# Decisions: 덱스 탈출 넘버원 5PM RUSH

- Date: 2026-11-01
- Status: Confirmed

## D01. 기술 스택과 배포
- **Chosen**: React + Phaser 3 + TypeScript, Azure Static Web Apps, Azure Functions, Azure Cosmos DB for NoSQL
- **Rationale**: 회사가 Microsoft 계정과 Azure 구독을 사용하므로 인증·배포·데이터 저장을 Azure 중심으로 통일한다.

## D02. 인증 대상
- **Chosen**: 회사 Microsoft Entra ID 테넌트의 모든 활성 사용자만 허용하는 Single-tenant 인증
- **Rationale**: 회사 구성원 전용 게임이며 게스트·개인 Microsoft 계정·다른 테넌트 사용자를 차단한다.

## D03. 인증 구현
- **Chosen**: Azure Static Web Apps 기본 Entra ID 인증
- **Rationale**: 로그인·세션·리디렉션을 Azure가 관리해 구현 복잡도와 인증 코드의 보안 부담을 줄인다.

## D04. 접근 범위
- **Chosen**: 인터넷 접속 가능, 단 로그인한 회사 사용자만 게임·랭킹·기록 접근
- **Rationale**: 재택·출장 환경에서도 사용할 수 있으면서 회사 조직원 전용 접근을 유지한다.

## D05. 공개 기록과 표시명
- **Chosen**: 조직원 전체가 모든 사용자의 최고 기록을 확인하며, 플레이어 표시는 Entra ID 표시 이름 사용
- **Rationale**: 조직 내 경쟁을 활성화하되 이메일·사번 등 불필요한 계정 정보는 기록에 저장하지 않는다.

## D06. 기록 저장 단위
- **Chosen**: 플레이어별 최고 기록만 저장하고 전체 기간 동안 유지
- **Rationale**: 장기 랭킹을 운영하며 데이터량을 제한한다. 동점이면 먼저 달성한 사용자를 우선한다.

## D07. 저장 데이터
- **Chosen**: 최고 거리, 최고 기록의 코인, 최고 점수, 최초 달성 시각, 누적 코인 잔액 저장
- **Rationale**: 상점은 후속 개발이지만 코인은 지금부터 누적해 향후 제트팩·스킨 구매에 사용할 수 있게 한다.

## D08. 결과 저장 신뢰 모델
- **Chosen**: 초기 사내 프로토타입에서는 클라이언트가 보낸 결과를 그대로 저장
- **Rationale**: 직접 플레이와 비조작을 전제로 빠르게 게임성을 검증한다. 공식 대회·보상·상점 도입 전에는 서버 검증이 필요하다.

## D09. 저장 실패 처리
- **Chosen**: 결과 화면을 유지하고 저장 재시도 버튼 제공; 새로고침·창 종료 시 대기 결과 폐기
- **Rationale**: 사용자가 실패 사실을 확인하고 직접 재시도할 수 있으며, 초기 버전의 오프라인 큐 복잡도는 피한다.

## D10. 게임 조작
- **Chosen**: 최신 Chrome·Microsoft Edge 기준 PC 키보드 전용, 스페이스바 누름으로 상승·해제로 하강
- **Rationale**: 회사 PC 환경을 우선하고 브라우저별 테스트 범위를 줄인다.

## D11. 화면 비율과 UI
- **Chosen**: 16:9 기준 캔버스를 비율 유지로 확대·축소하는 고품질 한국어 UI
- **Rationale**: 레퍼런스의 패널형 HUD와 회사 시설 분위기를 유지하면서 다양한 PC 화면에 대응한다.

## D12. 시작 흐름과 사운드
- **Chosen**: 로그인 후 사운드 자동재생 시도, 게임은 시작 버튼을 눌러 시작; 우측 상단 음소거와 설정 아이콘 제공
- **Rationale**: 브라우저 자동재생 제한을 고려해 첫 사용자 클릭을 게임 시작 트리거로 삼고, 사용자가 사운드를 제어할 수 있게 한다.

## D13. 시작 연출
- **Chosen**: 약 3초 동안 4:59:59에서 5:00:00으로 바뀌는 회사 벽시계, 알람, 부스터 점화 후 비행 시작
- **Rationale**: “5시 정각” 콘셉트를 반복 플레이에 부담 없는 짧은 연출로 강조한다.

## D14. 자동 일시정지
- **Chosen**: 설정 메뉴에서 일시정지·재개 제공; 캔버스 밖 클릭·탭 전환·창 포커스 해제 시 자동 일시정지; 재개 시 3·2·1 카운트다운
- **Rationale**: 자리 비움 중 진행을 막고, 복귀 순간 장애물 충돌을 방지한다.

## D15. 캐릭터
- **Chosen**: 제공 사진을 기반으로 얼굴 특징을 최대한 살린 2D 카툰 일러스트, 밀짚모자로 머리카락을 가리고 갈색 가죽가방을 제트팩으로 사용
- **Rationale**: 사진과 유사한 얼굴을 유지하면서도 게임 그래픽과의 이질감을 줄인다. 원본 사진은 제작 참고용으로만 사용하고 최종 게임에는 일러스트 에셋을 사용한다.

## D16. 에셋 구조
- **Chosen**: 캐릭터, 모자, 가죽가방 제트팩, 부스터, 코인, 방어막, DEX 토큰, 장애물, 배경을 독립 에셋으로 관리
- **Rationale**: 콘텐츠별 업데이트·교체가 쉽도록 원본 에셋·에셋 레지스트리·게임 로직을 분리한다. 캐릭터·장애물은 고해상도 PNG, UI·아이콘은 SVG/벡터 기반을 사용한다.

## D17. 토큰과 아이템
- **Chosen**: 제공한 `DEX.` 로고를 토큰 크기에 맞춰 사용; 코인과 달리 정의된 이동 패턴을 무작위 선택해 이동; 토큰 3개 소모 시 5초 부스터 발동
- **Rationale**: 토큰을 고난도 수집 목표로 만들고 회사 정체성을 반영한다. 이동 패턴은 상하·좌우·물결·원형 등 학습 가능한 패턴으로 구성한다.

## D18. 부스터
- **Chosen**: 시작 시 5초, 토큰 3개 획득 시 5초; 무적·고속 이동·화면 오른쪽 이동 후 기본 위치 복귀
- **Rationale**: 시작 몰입감과 토큰 수집 보상을 모두 제공한다. 부스터 발동 후 토큰 카운트는 0으로 초기화한다.

## D19. 방어막
- **Chosen**: 장애물 1회 충돌 방어, 중첩 불가; 방어막 아이템 최소 등장 간격은 1,100m
- **Rationale**: 부스터와 다른 생존 자원을 제공하면서 희소성을 유지한다.

## D20. 충돌과 경계
- **Chosen**: 위 경계는 살짝 튕기는 최대 높이 표시이며 충돌 판정 없음; 아래는 바닥이고 닿으면 달리는 모션; 일반 장애물 충돌 시 종료
- **Rationale**: 상승·하강 조작을 직관적으로 전달하고 바닥에서도 다시 비행할 수 있게 한다.

## D21. 장애물과 공정성
- **Chosen**: 수직 레이저, 가로 레이저, 미사일, 몬스터를 사용하며 미사일·일부 특수 장애물만 우측 화살표로 예고
- **Rationale**: 예측 가능한 위험과 즉각 반응 위험을 섞는다. 일반 패턴은 회피 경로를 보장하지만 각 1,000m 구간에 최대 1회의 강제 충돌 패턴을 둘 수 있다.

## D22. 강제 충돌 패턴
- **Chosen**: 강제 충돌 전 방어막이 먼저 무작위 위치에 등장하며, 방어막을 놓치면 충돌 시 게임 종료; 강제 패턴 자체는 예고하지 않음
- **Rationale**: 방어막 수집과 판단을 요구하는 고난도 구간을 만든다. 방어막이 등장하지 않은 상태에서는 강제 패턴을 생성하지 않는다.

## D23. 배경 구간
- **Chosen**: 1,000m마다 변경되는 5개 구간: 사무실·복도 → 보안 게이트·주차장 → 도심 고층빌딩 → 지하철역·지하철 내부·지상 탈출 → 야간 하늘·옥상
- **Rationale**: 회사 탈출 서사를 거리 진행과 연결하며, 추후 5개 이상 구간으로 확장한다.

## D24. 속도와 난이도
- **Chosen**: 시작부터 속도감 있는 빠른 아케이드형, 1,000m마다 약 15% 증가, 5,000m 이후 최대 속도 유지
- **Rationale**: 초반부터 긴장감을 주고 구간 전환마다 난이도 상승을 체감하게 한다.

## D25. 게임 종료와 결과 화면
- **Chosen**: 충돌 시 캐릭터가 몇 바퀴 구르고 쓰러진 뒤 회색화; 결과 화면에서 거리·코인·최고 기록 갱신·순위를 표시
- **Rationale**: 충돌 피드백을 분명히 하고 재도전 동기를 제공한다. 최고 기록 갱신 또는 1위면 “멋쟁이네~”, 그 외에는 “재미난 친구네 ?”를 표시한다.

## D26. 랭킹
- **Chosen**: 최고 거리 기준 TOP 10과 현재 사용자 순위 표시; 결과 화면 진입 시 최신 랭킹 1회 조회
- **Rationale**: 화면을 단순하게 유지하면서 사용자의 경쟁 위치를 알려준다. 동점은 먼저 달성한 기록 우선이다.

## D27. 상점 범위
- **Chosen**: 초기 버전에서는 상점·스킨 구매 UI를 구현하지 않고 누적 코인 저장만 구현
- **Rationale**: 핵심 게임 루프와 인증·랭킹 검증에 집중하고 후속 콘텐츠 확장을 위한 데이터만 준비한다.
